# Dataset

`synthetic_retail.csv` is a synthetic retail transaction dataset included for reproducible demonstration of this project. It contains realistic customer, product, transaction, regional, discount, and seasonal patterns.

The notebook can also process a real retail/e-commerce CSV placed at `data/retail_dataset.csv`, provided it contains the required transaction fields described in the main README.

The synthetic dataset should not be interpreted as proprietary or real company data. For real-world datasets, always follow the source dataset's license and usage terms.
